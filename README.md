# Roast N' Toast Specialty Coffee — موقع تجريبي احترافي (Demo Prototype)

موقع إلكتروني عصري وفاخر مُصمم خصيصاً لكافيه **Roast N' Toast Specialty Coffee** بمدينة الإسماعيلية (حي الشيخ زايد)، بهدف تقديمه لإدارة الكافيه لإقناعهم بالتعاقد والتدشين الرسمي.

---

## ☕ المميزات الرئيسية للمشروع

1. **تصميم فاخر وعصري (Specialty Coffee Aesthetics):**
   - ألوان الهوية: درجات بني الإسبريسو الداكن (`Espresso`)، الكريمة الهادئة (`Cream`)، الكراميل والبيج (`Caramel`)، مع لمسات ذهبية راقية.
   - خلفيات زجاجية (Glassmorphism) وتأثيرات انسيابية راقية وسريعة.

2. **دعم كامل للغتين (العربية والإنجليزية):**
   - تبديل فوري وسلس بين العربية (RTL) والإنجليزية (LTR).
   - ترجمة احترافية شاملة لجميع النصوص، القوائم، الأزرار، والرسائل.

3. **استخدام صور حقيقية تم تنزيلها وتوثيقها للكافيه:**
   - صور فعلية لواجهة وديكور الكافيه الداخلي (Interior & Design).
   - صور حقيقية لقهوة V60 واللاتيه والمشروبات المنعشة.
   - صور حقيقية لساندويتشات التوست المحمصة وتشيز كيك سان سيباستيان والتيراميسو.
   - مجلدات الصور منظمة في `public/images/cafe/`.

4. **نموذج طلب حجز طاولة تفاعلي عبر واتساب:**
   - يتيح للعميل إدخال (الاسم، الهاتف، عدد الأفراد، التاريخ، الوقت، الملاحظات).
   - يقوم بتجهيز وإرسال الرسالة التلقائية المطلوبة نصياً إلى رقم واتساب الكافيه المباشر (`+201503001914`).
   - تنبيه توضيحي بأن الحجز هو طلب مسبق يتطلب تأكيد موظفي الكافيه.

5. **قائمة طعام تفاعلية (Menu):**
   - تصنيفات: (Hot Coffee, Cold Coffee, Specialty Drinks, Tea, Food & Toasts, Desserts).
   - شارة توضيحية شفافة بأن الأسعار نموذج تجريبي (Demo) لتسهيل مراجعتها مع المالك.

6. **معرض صور مزود بنافذة تكبير (Lightbox Modal):**
   - إمكانية استعراض الصور بكامل الشاشة والتنقل بينها بسلاسة.

7. **خريطة Google Maps وتواصل مباشر:**
   - خريطة تفاعلية مدمجة بالإحداثيات الدقيقة للكافيه في الشيخ زايد.
   - أزرار اتصال مباشر وحصول على الاتجاهات ومراسلة واتساب وحساب إنستغرام.

---

## 🛠 التقنيات المستخدمة

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Custom CSS Variables
- **Icons:** Lucide React
- **Typography:** Cairo & Amiri (عربي) + Outfit & Playfair Display (English)
- **SEO & Schema.org:** مهيأ بالكامل بمخطط Google Rich Snippets لمحلات القهوة.
